## Sobre
**ProjetoLogin01** é um projeto de portfólio que serve como base para evoluções futuras.  
Este repositório está **no início do desenvolvimento** — há muitas funcionalidades planejadas e melhorias a implementar. O objetivo é demonstrar conhecimento prático em construção de aplicações web, com atenção a segurança e validação pelo lado do servidor e integração frontend/backend.

> ⚠️ **Observação:** este projeto está em fase inicial. Caso queira usá-lo, usar apenas como referência para estudos — não deve ser usado em produção sem revisões de segurança entre outros.

---

## Tecnologias (stack usada)
- **Frontend:** HTML5, CSS, Bootstrap5, JavaScript
- **Backend:** PHP Orientado a objeto, PDO, MVC
- **Banco de dados:** MySQL

---

## Funcionalidades (implementadas / previstas)

### Implementadas (baseado na versão v1.0)
- Página de cadastro (formulário HTML)
- Página de login (formulário HTML)
- Autenticação básica via PHP + MySQL (PDO)
- Senha gravada com password_hash — **apenas como demonstração**

### Implementadas (baseado na versão v1.1)
- Sistema de segurança aprimorado para validação dos dados
- Sistema refatorado para MVC (Model, View, Controller)
- Usado PHP Orientado a objeto
- Verificação de login pelo banco
- Reaproveitamento do menu e algumas funções
- Router para substiruir o antigo switch case na questão de redirecionamento entre as páginas
- Validação de autenticação de sessão em todas as paginas
- Código inteiramente formatado e indentado usando as boas práticas da programação

### Planejadas / TODO
- Validação de entrada no servidor e no cliente (mais completa) ✅
- Implementar novas tabelas e relações entre elas 
- Melhorar o visual das paginas
- Sistema de recuperação de senha (token por e-mail)
- Sessões seguras (regeneração de ID de sessão, cookies com flags)
- UI responsiva e pequenas animações
- Documentação de API (endpoints) e exemplos de requests
